## Projects

### Damian Debugger

Intel VT-x와 EPT를 활용해 하이퍼바이저 계층에서 실행 흐름과 메모리 접근을 관찰하는 디버거 구조를 공부하며 구현하고 있습니다.

- VM-exit 기반 이벤트 처리 흐름 학습
- EPT hook을 이용한 메모리 접근 감시 구조 학습
- 디스어셈블리, 레지스터, 메모리, 스택 상태를 확인하는 분석 UI 구성

### Reversing CTF Problems

동아리 내부 해킹 대회에서 사용할 리버싱 분야 CTF 문제를 제작했습니다.

- 문자열, 조건 분기, 함수 흐름을 따라가며 풀이할 수 있는 문제 구성
- x64dbg, IDA, Ghidra 기반 분석 흐름 정리
- 문제 제작 후 write-up으로 분석 과정 문서화

### WPA3-SAE + Kyber on OpenWrt

캡스톤 프로젝트에서 WPA3-SAE 구조에 양자내성암호 Kyber를 통합하는 프로젝트에 네트워크 팀으로 참여했습니다.

- OpenWrt 펌웨어 빌드와 테스트 환경 구성
- hostapd, WPA3-SAE 인증 흐름, liboqs 연동 구조 학습
- 펌웨어 환경에서 보안 프로토콜이 동작하는 과정 확인
